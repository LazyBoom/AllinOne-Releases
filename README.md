# AllinOne for macOS

本仓库提供 AllinOne 成品下载、版本说明、问题反馈与功能建议，不包含应用源码。源码在独立私有仓库中维护；本仓库使用独立 Git 历史。

## 下载与升级

前往 [Releases](https://github.com/LazyBoom/AllinOne-Releases/releases) 下载适合当前 Mac 的版本。新版将直接从此公开仓库检查和下载更新，无需用户配置 GitHub Token。具体可用版本以 Release 说明为准。

当前为内测阶段，使用固定本地证书签名，尚未完成 Developer ID 签名与 Apple 公证。macOS 14 及以上；首批成品为 Apple Silicon。

## 问题与建议

在 [Issues](https://github.com/LazyBoom/AllinOne-Releases/issues/new/choose) 选择问题反馈、功能建议或新模块建议。请说明应用版本、macOS 版本、相关模块、复现步骤与预期结果。

Issue 正文与附件对公众可见，请不要上传 Token、密码、私人截图、剪贴板、便签、文件原文或未脱敏的完整崩溃报告。应用内反馈会明确展示将要提交的内容。

崩溃记录首先保留在本机；“异常退出”与“已确认崩溃”分别展示，不会把正常退出或升级重启直接算作崩溃。具体记录与提交能力以对应版本说明为准。

## 仓库范围

本仓库仅维护公开分发成品、说明与反馈模板；不包含本机数据、开发凭据、私有源码或私有仓库的 Git 历史。公开提供二进制不等于应用源码采用开源许可证。
